# Security Policy

## Supported Versions

Only the latest release of PEiD (`peid` on [PyPI](https://pypi.org/project/peid/)) receives security fixes.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them privately through [GitHub's private vulnerability reporting](https://github.com/packing-box/peid/security/advisories/new) (the repository's *Security* tab, then *Report a vulnerability*). Please include:

- the PEiD version (`peid --help` prints it);
- the steps to reproduce the issue, and a sample (or its hash) if relevant;
- the impact you expect.

You will get an answer as soon as possible. Once the issue is confirmed, a fix is released and the advisory is published.
